# 🔥 Yapay Zeka ile Yüksek Sıcaklıkta Dayanıklı Süper Alaşım Tasarımı

Bu proje, makine öğrenmesi tabanlı regresyon modelleri kullanılarak yüksek sıcaklıkta maksimum mekanik dayanım sağlayacak süper alaşım kompozisyonlarının tahmin edilmesi amacıyla geliştirilmiştir.

---

# 📌 Proje Amacı

Bu proje kapsamında farklı alaşım bileşimleri ve ısıl işlem parametreleri kullanılarak mekanik dayanımın tahmin edilmesi amaçlanmıştır.

Python ile veri analizi gerçekleştirilmiş, regresyon modelleri uygulanmış ve model performansları karşılaştırılmıştır.

---

# 🚀 Gerçekleştirilen İşlemler

- Veri seti üzerinde ön işleme çalışmaları gerçekleştirildi.
- Regresyon tabanlı makine öğrenmesi modelleri geliştirildi.
- Alaşım özellikleri ile mekanik dayanım arasındaki ilişkiler analiz edildi.
- Eğitim ve test veri setleri kullanılarak model performansları değerlendirildi.
- Korelasyon analizi ve veri görselleştirme teknikleri uygulandı.
- Overfitting ve underfitting analizleri gerçekleştirildi.

---

# 📊 Performans Değerlendirmesi

Model performansı aşağıdaki metrikler kullanılarak değerlendirildi:

- Mean Squared Error (MSE)
- R² Skoru
- Eğitim ve Test Başarı Karşılaştırmaları
